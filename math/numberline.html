Number Line

How to use Number Line
  1. Set the first and last whole numbers, or use a preset. The last must be greater than the first; the line supports up to 100 spaces between −1000 and 1000.
  2. Show the line, then tap a number or near the axis to choose your start. That starting number appears above the line.
  3. Tap another number to make a jump. Rightward movement adds; leftward movement subtracts. Jump size counts spaces crossed, not number of taps.
  4. For example, 5 → 4 → 3 → 2 and a direct 5 → 2 both produce 5 − 3, with the final 2 circled. On updated versions, arch labels show cumulative displacement from the initial number.
  5. Undo removes the most recent jump. Clear line removes the plot but keeps the selected range. Wide lines scroll horizontally; arrows/Home/End move keyboard focus and Enter/Space selects.
  6. Copy link and Add to lesson preserve the range, starting number and plotted destinations. Existing lesson timers and Done work when opened from a checklist.
