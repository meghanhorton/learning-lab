How to use Lesson Plan
  1. A plain Lesson Plan URL loads examples/Week-2-November-2-2026.json. Explicit shared lesson links and imported plans keep their own content; saved progress for the same default lesson is retained.
  2. Use Edit to change titles, sections and activities. Add or reorder sections, then enable Create mode to choose a destination section and open a tool.
  3. In a tool, enter or choose content, then Add to lesson. Review the activity name and target section before saving. Story libraries can add an individual example directly.
  4. Worksheets and book readings can be entered without a URL. Add their title, pages/chapter reference and notes. These are checklist entries, not web links.
  5. Check an activity when complete. For timed web activities, open it from this checklist and use Start/Pause/Reset and Done to record time and return.
  6. Copy/Share creates a snapshot link; devices do not live-sync. JSON export/import preserves the lesson and recorded state. New lesson creates a separate blank plan.
  7. Weekly PDF exports current checked states and activity links; its reporting week is a label, not an automatic historical filter. Drive backup controls, if installed/configured, save separate JSON copies.

Changes save in this browser. Share the current link to transfer the lesson, checkboxes and recorded times to another device. Devices do not live-sync.
