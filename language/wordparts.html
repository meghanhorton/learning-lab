Word Parts

How to use Word Parts
  1. Enter the shared part, such as all, without requiring hyphens. Add a word list separated by commas, spaces or line breaks, such as all, ball, call, small.
  2. Every word must contain the selected part. If an error lists words, correct them or choose a different part before starting.
  3. Add optional letter combinations or whole sight words. Dolch is enabled by default and supplements your list. To emphasize only the selected part, turn Dolch off and leave the whole-word box empty.
  4. Start, say the word part on the introduction screen, then select Let’s read. Drag the dot across a word and release when complete; the next word appears after a short pause.
  5. The common part remains visually anchored while the other letters change. Use Previous/Next for manual navigation; CSV example controls appear for multiple examples.
  6. Edit changes the setup; Copy link preserves the settings. In Create mode, Add to lesson adds the current word-part practice to your chosen section.

The part can appear anywhere in a word. Complete and release each word to advance automatically.
