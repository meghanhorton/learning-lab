How to use Story Slider
  1. Search by the lesson skill or story title. The result count updates as you type; the original source attribution and PDF-page references remain with the stories.
  2. Open a story link to read the full passage in Reading Slider. Adjust text size or emphasis with Edit if needed; Dolch whole-word emphasis is on by default unless the link says otherwise.
  3. Use a story’s Add to lesson button, when installed, to add that single full passage. Confirm its name and destination section; the library itself is not added as an activity.
  4. Open this library from Create mode to retain the chosen lesson and section. You can also create your own reading instead of choosing a prepared story.
