Sentence Pyramids

How to use Sentence Pyramids
  1. Enter one sentence-building step per line, beginning short and adding words on later lines. For example: We / We can / We can read. Put each step on its own line, not slash-separated.
  2. Choose text size and optional letter-combination and whole-word emphasis. Dolch is off by default. Check it to add the built-in list to your custom whole sight words.
  3. Start reading and drag across the first unfinished line. Release when finished. Completed lines become muted and the next line becomes active.
  4. Text stays at the requested size. Tall pyramids continue onto additional pages; wide lines can scroll horizontally. The active page is brought into view as you progress.
  5. CSV can hold several separate pyramid examples. Use the bottom example controls/dots to switch examples.
  6. Use Edit or Copy link in the bottom bar. In Create mode, Add to lesson saves the pyramid; when you use a ready-made library, its Add to lesson button saves that selected example.
