Letter Tiles

How to use Letter Tiles
  1. Enter single spelling words separated by commas, spaces or line breaks. Use letters only; repeated words are combined. The list supports up to 200 words.
  2. Start practice. The answer list is hidden from the board; the letter bank contains the letters needed for those words and can be reused.
  3. Say a word aloud, then drag letters to the board or tap letters to add them. Reorder tiles by dragging; remove a tile with its small remove button.
  4. Use Delete, Clear and Check in the bottom toolbar. Matching words receive feedback and enter the completed list; after a short pause the board clears for the next word.
  5. Keyboard users can add a bank letter with its button, move a focused board tile with left/right arrows, or remove it with Backspace/Delete.
  6. Edit changes the spelling list, Copy link shares it, and Create mode allows Add to lesson. Shared URLs contain the spelling list, so the hidden on-screen list is not a security feature.
